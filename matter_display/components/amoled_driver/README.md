# amoled_driver

Display + touch + power bring-up for the **Waveshare ESP32-C6-Touch-AMOLED-1.8**
(SH8601 QSPI AMOLED 368×448, FT3168 capacitive touch, AXP2101 PMU, TCA9554 IO expander)
with an LVGL 8.4 port.
